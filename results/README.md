# Output directory

Everything here is produced by code in the repository; nothing is edited by
hand. Third-party input data never land here (they are in
`empirical/data/raw/`, gitignored).

```
results/
  simulation/            Monte Carlo study (root-level drivers, montecarlo/)
    mc_headline_<dgp>.mat / _*.csv / _meta.txt   the five-estimator headline runs
    mc_final_*, mc_fmar_*, mc_sparse/correct/dense   earlier four-estimator runs (kept, not comparable term by term)
                         (mc_fmar_sanity_* are Octave text-format files: readable by Octave, not by MATLAB;
                          REPORT.txt was generated under Octave and is kept as tracked)
    grid/                the 13-cell exploratory grid (+ grid_summary.csv)
    sensitivity_approximations.csv               what the remaining approximations cost
    REPORT.txt           regenerated by montecarlo/write_results_report.m
    figures/             fig1..fig5 (RUN_ME_FIRST), fig_fmar_irf_sparse.png (RUN_FMAR_DEMO)
  empirical/             Chapter 7, current design (empirical/RUN_EMPIRICAL_IV.m)
    iv_<system>_p<p>.mat                 step A: BVAR, BLP-FMAR, BLP-block, BLP-pooled, LP-LA, LP-IV, alternatives
    iv_<system>_p<p>_relevance.{mat,csv}  first stage / placebo / influence / anatomy for every instrument
    iv_<system>_p<p>_relevance_headline.csv   the headline instrument's full report (long format)
    iv_<system>_p<p>_irf.csv, _lpiv.csv   IRFs (25 bp scale) and the LP-IV table with Anderson-Rubin sets
    iv_<system>_p<p>_tau_heatmap.csv      tau by (estimator, equation, block, horizon)
    iv_<system>_p<p>_tau_protocol[<v>].csv, _protocol.mat   the reading protocol against each null
    iv_<system>_p<p>_pooled_H12.mat       the pooled estimator re-run at the null's H
    iv_<system>_p<p>_tau.mat              step D runs at the other lag orders
    iv_<system>_cross_p.csv               the cross-p / cross-null table
    null_calibration_<stem>[_wild].mat, .key.txt, null_thresholds_<stem>.csv   the nulls (stem iv_<system>_p<p>)
    ablation_<stem>.{mat,csv}             out-of-sample block ablation
    figures/                              fig_iv_*_irf.png, fig_iv_*_tau_{block,pooled}.png
    legacy_v1/                            the 2026-09-12 internal-instrument outputs (p12*, levels, their nulls, figures/)
```

Systems: `ois4` (headline: end-of-month 1M OIS, IP, SA HICP, STOXX),
`ois4_yoy`, `ois4_nsa`, `ois4avg_nsa` (variants), `lev4`, `lev4_yoy` (the
12M-Euribor systems of the 2026-09-13 dress rehearsal).

## Which number to quote

* **Simulations:** the integrated RMSE over `h = 2..H` (`irmse_h2` in
  `*_integrated.csv`). The `h = 1..H` version is kept for compatibility and
  is not a fair estimator comparison under the FMAR `h = 1` convention.
* **Empirical tau map:** never the raw `tau_bar`, which is measured relative
  to a tightness that differs by lag order and system. Quote the ratio to
  the null 95th percentile, the Monte Carlo p-value `p_mc` and the
  family-wise `p_fwer` from `*_tau_protocol*.csv`, and say which null
  (iid resampling or wild bootstrap, `R`) they come from.
* **Empirical IRFs:** only with the first-stage effective F and, below the
  Montiel Olea-Pflueger 10%-bias threshold (23.1), the Anderson-Rubin sets
  from `*_lpiv.csv`.

Intermediate files (`null_ckpt_*.mat` checkpoints, `simulation/chunks/`,
`*_quick*` interface-check outputs) are gitignored.
